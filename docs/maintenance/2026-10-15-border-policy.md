# 边框、图片描边与内发光

按用户逐项确认的“12–20% 透明发丝线，图片不加框”落实本项。方案不同章节存在 7%、8–11%、10% 等较低边框值及暗色图片加内框的补充；本次以用户明确引用的 12–20% 与图片无框为准，不添加暗色图片伪元素内框。

## 核查结果与修改

上一轮中性色派生已将 `--bew-surface-border-color` 改为前景 12%，但未移除封面上的 `.bew-surface-border`，也未停用浅色/深色 `edge-glow`，因此本项此前只完成一部分。

- 分隔线、普通面板和消息卡片使用前景 12% 的 1px 线；输入边线 16%，悬停 20%。UnoCSS 默认边框以及原生 `line_light / line_regular / line_bold` 同步到这三个语义值。去除消息边框及动态页分隔线的二次透明混合，避免实际透明度继续乘低。
- `--bew-shadow-edge-glow-1/2` 统一为 `0 0 0 transparent`，删除深色的发光配方。保留这两个无效果兼容别名，使组合阴影列表中的浮起阴影和焦点阴影继续有效；不能改成 `none` 后与其他阴影逗号拼接，否则会使整条声明无效。
- 移除视频、番剧、专栏封面上的边框类，番剧/专栏骨架同步。移除评论图片、聊天图片与图片卡片、普通作者头像、动态直播预览、搜索活动封面、稍后再看叠放封面的装饰边框。
- 原生适配中，个人空间封面取消额外阴影框；账户头像图片、公共门户封面和活动奖品图片取消装饰边框。播放页加载样式及重连提示的边框降级色也使用透明色。
- 侧栏搜索的常态边线改为输入边线，hover 使用 20%，focus-within 保留原中性焦点反馈；下拉菜单边线使用共享 token。

卡片/面板边框、图片上方的独立按钮与排名徽标不是图片描边，保留发丝线。直播状态环、选中反馈、编辑辅助线、键盘焦点和必要分隔线保留。聊天图片原有 8px 留白、圆角、点击行为不变；没有移除气泡布局或图片裁切。页头、侧栏结构及几何、玻璃采样、页面切换动效不变。
