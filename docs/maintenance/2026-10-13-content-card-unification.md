# 内容卡片统一

本轮依据用户提供的静态审查规范核对实际源码，统一视频、动态、专栏、番剧及用户卡。用户明确要求移除旧视频布局，因此不保留审查文档中的旧布局例外。

## 实现

- `contentCard.scss` 复用裸卡与表面卡的悬停、键盘聚焦、按下及减少动态效果规则。裸卡以 8px 内距和等量负外距提供呼吸边，不使用会被 content-visibility 裁切的外溢伪元素。视频/番剧网格的行距由网格持有；虚拟列表继续读取实际 row-gap、共享测量并回收离屏卡片。
- `variables.scss` 集中卡片内距、区块间距、内嵌媒体圆角、封面操作尺寸及遮罩色。用户名默认中性前景，悬停/键盘聚焦再使用主题前景；点赞、热评等状态保留强调。
- 视频信息区仅保留一套模板；时间及分类以中点分隔，最多一个搜索标签。`VideoCardMeta.vue` 复用原有 wholeMeta 测量调度，不新增每卡监听器。字号、内容开关、预览及封面阴影曲线仍可配置。
- 封面操作使用统一 32px 圆形按钮、8px 边距、caption 统计与等宽数字。动态媒体/引用/热评使用 8px 内嵌圆角；热评内缩，页脚使用内缩圆角按钮并移除纵向分隔。嵌套转发视频采用普通实色阅读面。
- 专栏合并元信息与统计，日期复用本地化时间格式；番剧标题降到 title 层级，移除仅写入未消费 CSS 变量的 ResizeObserver；用户卡统一内距与悬停强度。骨架同步新布局。窄栏番剧外层显式 min-width:0，避免离屏宽度估算撑大网格。
- 删除视频布局设置、搜索入口、四语言文案、类型、默认值、旧模板及旧迁移分支。`videoCardLayout` 只在统一废弃字段表及迁移回归中保留，旧值在权威读取、导入和同步时丢弃，不恢复旧布局。

## 验证

- `pnpm test` 完整四套回归通过（662 条 PASS）；设置迁移覆盖旧布局字段，组件回归覆盖统一横/竖布局、时间优先、单搜索标签及共享元信息测量。
- `pnpm lint`、`pnpm typecheck`、`git diff --check` 通过。开发产物中已无布局设置文案或分支，`videoCardLayout` 仅存在于废弃字段表。
- 本机真实组件合成数据预览覆盖亮色、暗色、OLED、390px 窄窗口及骨架切换；发现并修复番剧离屏宽度估算溢出和更多按钮骨架透明问题。横版封面与信息区顶端齐平、间距实测 16px；封面操作与骨架圆钮均为 32px。普通卡片无新增 backdrop-filter，骨架切回内容后占位全部卸载。
- 使用既有开发 watcher 更新产物，不运行生产 build。实站重载验证另行记录；本地预览不代表真实账号写入或实站性能基准。

## 实站复验

用户重载后，动态页实测作者常态为 `rgb(241,242,244)`，键盘聚焦变为当前主题前景 `#f6677f`；媒体圆角 8px、页脚外高 40px。首页成功加载 39 张真实视频卡，作者为中性次要文字色，封面操作圆钮 32px。设置的视频卡片分类已无新旧布局开关，设置搜索“视频卡片布局”返回“没有找到相关设置”。未提交点赞、收藏或其他账号写入；日志仅出现原站 hydration 与另一扩展 BTR 错误。

发现开发 watcher 的共享 SCSS 增量缓存未更新网格行距，实站与当时 CSS 产物仍为 20px。已仅重启本任务持有的 watcher；完整开发编译成功，CSS 与注入脚本均确认包含列距 20px、行距 32px。普通页面刷新一度仍读取旧产物。用户再次手动重载扩展后复验通过：首页实际 column-gap 为 20px、row-gap 为 32px，卡片内距为 8px，44 张真实卡片加载完成、数据骨架为 0。本轮日志仍仅有原站 hydration 与另一扩展 BTR 错误，未见新增 Bewly 错误；网格行距验收已完成。
