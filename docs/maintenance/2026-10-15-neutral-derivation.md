# 中性色统一派生

> 后续修订：2026-10-16 用户批准按用途校准表面阶梯，当前数值与验收见 `2026-10-16-typography-surface-hierarchy.md`。本文保留此前派生体系的实施记录。

## 本次范围

落实《bewlyCat 界面优化方案》的“中性色色温”条目：由 foreground / background 一对来源派生中性色，muted 文字采用前景 67%，悬停采用前景 7%。保留用户后续确认的主题色按钮、可选深色色调，以及现有页头、侧栏、玻璃和动效。未套用方案中已被收窄的布局改版、移除玻璃或重建控件要求。

## 单一来源

`src/styles/variables.scss` 使用 `--bew-neutral-bg` 和 `--bew-neutral-fg` 两个主题原色。画布、内容、浮起表面、文字、填充、选中/按下、边框、输入和骨架都从该对原色计算。旧的 `--bew-dark-page-bg` 和 `--bew-dark-glass-base` 仅保留为兼容别名，不再独立调色。

| 语义 | 派生规则 |
| --- | --- |
| 正文 / 次级 / muted / 禁用文字 | 前景 100% / 76% / 67% / 38%，后三档通过透明度叠加所在表面 |
| 悬停 | 前景 7% 透明覆盖 |
| 选中 / 按下 | 前景 8% / 9% 混入实色内容面，保持现有实色状态控件；选中内环为前景 6% |
| 填充 1–4 | 前景 5% / 9% / 14% / 22% 透明覆盖 |
| 分隔线 / 表面边框 / 评论关系线 | 前景 12% / 12% / 12%（按后续边框修订统一） |
| 输入边框 / 悬停边框 | 前景 16% / 20%（按后续边框修订统一） |
| 骨架 | 前景 7%，共享骨架降级值也取消偏紫灰 |
| 深色内容 / 浮起表面 | 前景 3% / 6% 混入页面背景，不再从另一组深色基准单独抬高 |

浅色原色为白底与 `#171717` 前景，画布叠加 4% 前景；默认深色使用接近 `#121212` 的背景与 `#ebebeb` 前景。OLED 背景归零，表面仍从同一对原色派生。可选色调仅改变这对来源，限制背景与前景色度，关闭后继续保留用户保存的色值。

侧栏仍使用批准的浅色 6% / 深色 16% 中性分离比例及原透明度，保留层级和单次毛玻璃采样。物理阴影、媒体遮罩、固定黑白图标与品牌/语义状态色属于明确用途，未机械改为随主题反转的前景色。

## 原生页面与兼容

原生适配的 `Ga*`、`Si*`、`Wh0*` 和 graph 中性色改为相同派生链的别名。原站仍消费逗号分隔的 `*_rgb` 元组，因此 `syncNativeNeutralRgb` 直接读回 CSS 计算颜色生成元组，复用现有主题/色调/OLED watcher，不增加监听器、轮询或第二套 JavaScript 调色公式。Canvas 不可用时保留无色相的静态降级值。

主题色前景对比度采样补充侧栏和浮起次级悬停面。主操作底色仍等于用户原始主题色，只选择黑/白前景。

## 验证与实际值

`scripts/serve-neutral-preview.mjs` 使用实际生产 SCSS 与颜色工具，在普通文档及 Shadow DOM 两侧运行检查。14 组场景涵盖浅色、深色、OLED、四种可选色调及毛玻璃开/关；核验中性色无偏色、67%/7% 透明度、文本对比度、RGB 别名同步、OLED 纯黑、玻璃透明度和主题按钮原色。

| 模式 | 画布 | 内容面 | 浮起面 | muted 在内容面上的合成色 | 所测表面最低阅读文字对比度 |
| --- | --- | --- | --- | --- | --- |
| 浅色 | #f6f6f6 | #ffffff | #ffffff | #636363 | 5.54:1 |
| 深色 | #121212 | #181818 | #1f1f1f | #a5a5a5 | 5.61:1 |
| OLED | #000000 | #070707 | #0e0e0e | #9f9f9f | 6.44:1 |

预览检查 14/14 通过，浏览器无错误，并目视检查浅色、深色与 OLED。以上对比度指实际测试的实色语义表面，不代表任意用户壁纸下的透明玻璃都能保证相同结果。禁用文字不纳入阅读文字最低对比度。
