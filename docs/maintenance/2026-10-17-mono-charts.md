# 数据图表的 Mono 统一

## 范围与设计依据

用户指定安装 `larashero3-dotcom/lieflat-charts`，随后确认“所有图标”指项目中的所有数据图表，采用黑白灰为主、少量主题色。已通过 Codex 自带安装器安装至 `~/.codex/skills/lieflat-charts`，读取 SKILL、catalog、mono-tokens 和 Basics gallery 的 F1 / F2 / F4 / F5 实现。

只调整项目自己绘制的数据与参数图。导航小图标、原站网页内的图表、媒体图像、加载旋转环和播放进度控件不是本次数据图表范围。保留用户此前批准的轻字重、主题派生、卡片几何与两列四卡布局，不照搬技能的 Inter 700/800、浅色固定底、24px 外框或整页报告模板。用 Vue 组件表达模板的刻度、日历基线、细线和空心 / 实心点结构；未加入第三方图表库、模板脚本、远程字体或模板示例数据。

## 选型与覆盖

| 位置 | 采用的结构 | 候选比较 |
| --- | --- | --- |
| 消息概览未读通知 | F1 Rung Bars，竖向刻度柱 | L2 逐个点会随未读量增长；F5 横向行会改变现有四列导航；F1 保留列与共同基线，以标注的 1/2/5×10ⁿ 单位限制最多 20 格 |
| 会话七日活动 | F2 Hairline Line，日历底线、每日点、灰阶双序列 | L3 面向长序列；L11 表达事件生命史而非数值；F2 对应七日聚合，实线实心 / 虚线空心区分两种来源 |
| 未读私信来源 | F4 Tick Donut，100 个百分比刻度 | L14 百点网格会扩大现有 96px 槽位；L5 需要逐条归属记录；F4 保留中心总数与两项真实计数，明确标注每刻度约 1% |
| 动态投票结果 | F5 Tick Rows，独立百分比刻度行 | L15 的多选语义可用但大幅扩展卡片；F7 堆叠会错误要求总和为 100%；F5 保持每选项的独立参与人数分母。用户追加要求后使用每刻度 1%，小数末格保留比例 |
| 本地响度 | F2 的细线、刻度与当前读数 | L3 不适合 60 个局部增益样本；G17 流式面积会改变有正负的增益表达；使用原真实采样，仅标 +6/0/−18 dB 与最新点，不把采样次数伪称秒数 |
| 阴影曲线编辑器 | F2 细线 / 节点语法用于既有参数坐标 | F3 面积不表达额外数据；F8 散点会丢失插值控制关系；保留原坐标与编辑语义，减少网格、删除无语义填色，仅选中点使用主题色 |

## 实现约束

- `--bew-chart-primary/secondary/grid/surface/accent` 从当前中性色对及现有主题前景派生，移除独立蓝色。数据本身不使用渐变、透明度或发光；字号、线宽和状态色共用 token。
- `ChartRungs.vue` 与 `chartScale.ts` 共用柱 / 条刻度；0、未知、非法值没有数据格。小数末格按实际余数绘制，不通过最小高度夸大非零值；数值标签保持精确。通知每格单位随量级变化，所有类别共用同一单位。
- 活动图仍只统计每个已载入会话的最近活动时间，不读取或声称完整私信历史；保留逐日键盘焦点、点击、Escape 和文本读数。重合的两个系列使用同心实心 / 空心点。
- 响度轴标签使用固定 12px 的 HTML 文字，避免窄屏 SVG 缩放成小字；采样与音频处理流程不变。
- 阴影 Canvas 保留 DPR 处理、拖动、建点、删除与键盘调整；窄屏缩放后的鼠标坐标转换回内部坐标，不改变端点约束。
- 不增加点击重播以占用既有导航、读数、投票或编辑动作；继续使用应用原有进场与 reduced-motion 规则，没有新建逐帧动画或采样定时器。

## 验证

- 537 项 `verify-selected-p2` 回归通过，包括新增的有界刻度、零 / 未知值、小数余数，以及消息概览的 100 刻度、真实计数与导航 / 已读行为。
- 真实组件预览 `pnpm preview:charts` / `http://127.0.0.1:4348/`。账号、会话、投票和音频使用本地固定 fixture，投票写入入口主动拒绝；没有真实投票、私信读取或账号修改。
- 检查浅色 / 深色 / OLED、全零、未知、悬殊计数；390px 与 320px 无横向溢出，320px 曲线可选中并用方向键调整，已恢复 Chrome 临时视口。
- 投票加密后 65% 绘制 65 格，53.3% 绘制 53 格加 0.3 格，0% 不绘制格子；说明同步为每刻度 1%。
- 扩展实站检查需在全部代码验证及开发产物更新后，再重载扩展并刷新对应页面；预览不替代实站验收。
