## 补齐的现有遗漏

1. **有效主题状态同步**：必要设置监听与独立原生页面原先监听本地色调/OLED 设置。现在直接监听 `useDark` 输出的有效 `darkModeBaseColor / isOledDark`，父页面 iframe 主题继承变化也会刷新对比度与 RGB 投影，即使本地设置和 `isDark` 没变。
2. **未完成区域的恢复**：番剧页分别记录追番、热播、推荐是否完成，返回时仅恢复未完成区域的请求，成功的空列表也视为已完成；旧实例迟到响应不得进入新实例。动态页补充 portal 完成状态，避免信息流已完成但左栏数据未完成时，返回后永久缺失左栏数据。
3. **语义颜色遗漏**：两类原生通知的未读点改用 `--bew-accent-marker`；私信历史搜索关键词改用 `--bew-theme-foreground` 与透明底，和既有关键词规范一致。

## 代码质量、复用与硬编码

- CSS 仍是中性色派生的唯一来源。`themeColor.ts` 将两套重复的 Canvas 读色循环合并成一个内部批量读取函数；先完成全部读取再写样式，跳过相同值，失败时清掉旧主题的 RGB 投影，使用当前模式的 CSS 降级值，避免半新半旧的颜色。
- 删除已无调用的 `hexToHSL`，没有保留第二套 HSL 灰阶转换路径。
- 验证与预览脚本注册为包命令；颜色与图标检查加入 `pnpm test`，避免交付后只能靠临时命令发现。同步 Knip 的真实入口，移除已不适用的依赖忽略项。
- 页面切换仍复用 `useReadyPageTransition`、视图快照仍复用 `usePageViewState`、主题基准仍复用 `resolveDarkModeBaseColor`；未增加新路由器、全页 KeepAlive、重复主题存储或额外轮询。
- 保留有明确用途的兼容降级色、缓存容量、物理阴影、媒体遮罩及功能性焦点/直播状态环，未用全局 SVG 或图片规则覆盖业务状态。
