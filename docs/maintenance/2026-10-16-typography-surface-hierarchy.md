# 文字层级与视觉表面阶梯

> 当前文字规则以文末“常规字重、灰度与缩进”修订为准；前面的 500/600 记录是本日较早版本，不再代表最终字重。

## 授权范围

用户批准引入前一轮预览中的文字层级与表面阶梯，并移除通用设置的重复内容标题；明确拒绝“外壳贴边 / 内容在自己的容器里”的布局改版。本轮不改变顶栏、侧栏、设置窗口的位置、尺寸、布局结构、玻璃参数或页面切换行为。

灰阶依用途与实际相邻表面校准，不用相等的 RGB 增量、混合比例或 OKLCH 明度差作为视觉验收标准。沿用前景 / 背景两个中性色来源；百分比用于复现选定效果，不生成每层自动抬亮的链路。

## 实现

- `variables.scss` 补齐 14/20 的 ui、17/24 的 subheading、13/20 的 help，以及标题 / 标签字重角色。
- `main.scss` 统一 `.bew-page-heading`、`.bew-subheading`、`.bew-section-label`、`.bew-ui-label`、`.bew-help`；设置区块、分组、子分组、行标题、说明和普通弹窗复用这些角色，删除组件内重复字号组合。警告说明仍保留语义颜色。
- 设置面包屑当前项由 20/28 600 改为 500。通用正文移除重复标题与其装饰图标，保留说明、分组、原有控件及其状态。设置导航中的“通用”仍是导航项。
- 默认深色背景略提至约 `#141414`，内容约 `#1b1b1b`，浮层约 `#252525`，内嵌输入约 `#171717`。`--bew-elevated-alt-solid` 归于同一浮起角色，避免弹窗再额外抬亮。浅色与 OLED 单独校准；可选色调仍只改变两个来源。
- 新增 `--bew-neutral-inset`，Input、Select、设置搜索框复用 `--bew-input-bg`，Select 悬停使用 `--bew-input-bg-hover`；不改尺寸、事件、disabled、label、键盘或焦点权限。
- 保留 12–20% 边框、图片无框、零 edge-glow、原始主题按钮色与对比前景，以及原侧栏分离比例、玻璃透明度和采样方式。

## 同日追加：未读数字胶囊磨砂

用户明确要求 Dock 与顶栏的数字胶囊背景由实色改为磨砂。两处共用 `CountBadge.vue`，此次仅在该组件添加 `backdrop-filter` 与 WebKit 前缀，沿用 `--bew-filter-glass-1`。这是用户指定的 Dock 嵌套玻璃例外，不推广到其他控件。

`--bew-count-badge-bg` 从浮起面派生，着色透明度下限 76% 以保护小号数字在复杂页面内容上的可读性；沿用全局透明度，关闭毛玻璃后变为 100% 并停止滤镜。不支持背景滤镜时保留实色降级。计数来源、99+、零值隐藏、字体、20px 高度、圆角、位置及点击穿透不变。

实际组件检查覆盖浅 / 深 / OLED 的透明背景、20px 高度、12px 字号、1 / 28 / 99+ 与零值隐藏，以及关闭毛玻璃后的不透明背景和 `backdrop-filter: none`。Dock 实际组件的计数与壳体回归及提醒分类回归通过；相关 ESLint 与差异检查通过，主脚本和主 / 原生样式已更新。扩展重载后的实站检查与前述修改合并进行。

## 同日修订：常规字重、灰度与缩进

用户认为加重后的部分文字不够精致，要求通过黑白程度与缩进表达层级。共享的 heading / subheading / label 字重角色均改为 400；页面和区块 / 弹窗标题使用 text-1，设置分组、子分组及字段名称使用 text-2，说明保持 text-3。字号、行高、玻璃、表面与控件尺寸不变；不全局替换原有卡片、品牌、计数与语义强调的字重。

设置分组面板的内容起点向内移动 `--bew-settings-level-indent`（8px），嵌套子分组的内容再内缩一级。使用逻辑方向 padding，右侧控件对齐与原有响应式换行保留；外壳、页头和侧栏不作布局改版。

真实组件计算样式确认所有上述角色均为 400，组内与子组的实际缩进分别为 8px。浅色、深色、OLED 检查正常；Chrome 390px 窗口下字段保持在视口内且无水平溢出。修改文件 ESLint、2 项既有字体回归与差异检查通过。旧监听器已退出，重新启动本仓库 `pnpm dev`，主样式及原生样式已更新。实站验收仍需扩展重载后进行。
