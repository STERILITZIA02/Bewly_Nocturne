# 唱片阴影、听视频延续与页面切换（2026-11-13）

## 唱片

唱片从弹窗使用的 `--bew-shadow-4` 改为共享的轻阴影 `--bew-shadow-1`，去掉宽内圈的硬叠边，细边亮度从 55% 降到 28%；唱臂阴影缩小并从 28% 降到 16%。不修改全局阴影 token、唱片尺寸或转动方式。源码与开发产物已检查，观感由用户目测。

## 听视频模式的延续

`listenControl.ts` 在当前标签页的 `sessionStorage` 保存已成功进入的模式。更换视频只结束旧媒体会话，保留模式选择；新视频元数据与当前路由一致、媒体就绪且不是广告后，经原有音源读取、DNR 授权和原生播放器交接启动听视频。

- 同文档导航、分 P、普通视频与番剧均走同一控制器；整页导航后恢复模式，原有检查点仍优先恢复同一视频的播放进度。
- 同一视频的自动进入只尝试一次，迟到的元数据不会不断重试。手动返回视频模式或取消自动进入会清除模式选择。
- 原有 BTR 保留媒体所有者、旧授权释放及路由身份验证继续生效。
- 普通播放器 DOM 更新不会重复请求元数据；回归夹具的 50 次无关 DOM 更新新增读取为 0。
- 唱片的普通视频信息复用 `getPlaybackVideoInfo`，与简介栏、观看进度和评论修复共享读取。上一视频迟到的信息、字幕轨道与歌词不再覆盖当前舞台。

## 各页面的保留与更新边界

沿用 `usePageViewState` 的账号隔离、24 个视图及约 8000 个数据条目的缓存预算。离开页面释放其 DOM、监听、定时器和请求，保留可恢复的数据；没有把所有页面放进 `KeepAlive`。

| 页面 | 处理 |
| --- | --- |
| App、顶栏、侧栏、Dock | 保留现有共享外壳及页面转场，页面模块仍只懒加载一次。 |
| 首页 | 保留现有首页外壳、分类快照及滚动位置；非活动分类释放数据请求与滚动订阅。 |
| 搜索入口 | 新增输入草稿快照。 |
| 搜索结果 | 七类结果统一保存已完成列表、页码、游标与加载更多状态；返回相同条件不重新搜索。关键词、筛选、账号、匿名模式、分页模式或编号页不一致则重新读取；关注关系仍由共享关系缓存按需确认。 |
| 番剧 | 保留原有分区快照；新增时间表及横向位置缓存。同一天返回复用，跨日期或手动刷新读取，离开取消未完成请求。 |
| 收藏 | 新增控制器快照，保留目录、封面、选中项、内容、查询及分页边界。账号或收藏变更版本不同、有写入或未完成/失败/待修复读取时重新加载；筛选扫描继续由原扫描控制器负责。 |
| 观看历史 | 保留现有时间线、筛选、游标和滚动快照及账号隔离。 |
| 稍后再看 | 保留现有队列快照与版本校验，队列变化时同步。 |
| 动态 | 保留现有阅读位置、筛选和 Feed 快照，非活动页面释放请求与刷新。 |
| 消息 | 保留现有按账号、未读和时效刷新的逻辑及非活动页面资源释放；不将私信正文加入通用页面快照。 |
| 播放页 | 同文档切换沿用外壳；音轨、评论、弹幕等跟随视频身份更新。普通视频的简介读取与听视频共享。 |

浏览器真正更换文档时仍需要初始化新文档的原生页面与扩展上下文；听视频模式会在同一标签页延续，不用整站自建路由取代 B 站原生页面。
