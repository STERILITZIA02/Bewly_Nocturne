# 收藏夹管理与切换加载

## 协议依据

2026-10-12 核对原站空间当前发布脚本：
<https://s1.hdslb.com/bfs/static/shanks/fresh-space/assets/index-76bd2e5f.js>。
交叉参考收藏接口文档：
<https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/fav/action.md>。

- 创建／编辑：`/x/v3/fav/folder/add`、`edit`，表单提交 `title/intro/cover/privacy/csrf`，编辑另传 `media_id`。名称最多 20 字符、简介 200 字符；新建默认公开（privacy=0）。编辑先读取 `folder/info`，不能用目录的简略对象覆盖简介或封面。原站默认收藏夹允许编辑，只禁止删除。
- 封面：`/x/upload/web/image`，multipart 的 `bucket=medialist`、`dir=cover`、`file` 与 CSRF，成功 URL 在 `data.location`。JPG/PNG，不超过 5 MB。未确认表单前只使用本地预览；提交时上传，换号和离场不继续提交收藏夹。
- 点赞：原站拼写为 `/x/v3/fav/thump/up`，`rid` 为完整收藏夹 ID、`type=11`、`thumb_type=1/2`。收藏／取消收藏使用 `folder/fav`、`folder/unfav`；禁止收藏自己的收藏夹。分享提供收藏夹播放页链接复制。
- 置顶：原站没有独立 pin 状态，使用 `folder/sort` 的完整 ID 顺序；默认收藏夹保持第一，目标放在其后。先刷新完整目录，其他项保持相对顺序；不是仅本地排序。
- 清理：`/x/v3/fav/resource/clean` 清理当前收藏夹全部失效内容，由服务器判定；不按标题或本地封面失败推断失效。不批量遍历其他收藏夹。

## 结构与审查修正

- `FavoriteFolderEditor.vue` 独立表单、`useFavoriteFolderManager.ts` 管理元数据和编辑生命周期；所有提交沿用 `useFavoriteWrites` 的账号快照和互斥。创建已成功但目录回读失败时关闭创建窗并提示刷新，避免重复创建。
- 空收藏夹也读取封面；刷新目录重新绑定选中项，避免编辑后继续引用旧目录对象。
- 全收藏夹搜索隐藏按“当前夹 ID”删除的入口，避免跨夹结果取消收藏归属错误。
- 删除／移动后按剩余已加载数量回退分页位置，避免 offset 变化跳过后续视频。
- 收藏内容、目录和元数据读取在替换／卸载时取消；加载目录不禁用分类滚筒。视频补页由 `VideoCardGrid` 哨兵负责，移除另一套递归补页；图文空视口补页保留。
- 收藏夹信息区展示 `folder/info.upper` 的创建者及空间链接。自己的收藏按钮保留但 disabled，其他收藏夹依据 `fav_state` 显示收藏/取消收藏；提交复用原互斥与账号归属，不以点击直接翻转状态。实站确认自己的创建者和禁用按钮。
- App 页面与 Home 分类复用 `createAsyncPageRegistry`，退出动画期间只预加载选中模块，不提前挂载数据层；共用加载 Promise，失败不永久缓存。
- 核对 History、WatchLater、Moments 的读取取消／布局与预览清理、Home 数据缓存、Notifications 会话与分类生命周期；保留已有实现，不添加整页 KeepAlive，不改冻结页面外观。
