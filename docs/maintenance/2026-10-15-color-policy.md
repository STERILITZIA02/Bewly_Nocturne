# 2026-10-15 配色修订

## 默认深色与可选色调

- 新增“外观 → 颜色 → 深色背景色调”，默认关闭。既有配置没有该字段时也使用中性灰。
- `resolveDarkModeBaseColor` 统一计算实际基准：关闭时为 `#2b2b2b`；打开时使用原有 `darkModeBaseColor`。关闭不清空预设或自定义色值，导入和同步沿用现有设置存储链路。
- 移除深色页面 OKLCH 配方中的最低色度限制。后续中性色派生修订已将默认画布/内容面/浮起面统一为约 `#121212` / `#181818` / `#1f1f1f`；当前值与推导见 `2026-10-15-neutral-derivation.md`，OLED 画布为 `#000000`。
- 初始 Shadow DOM 注入、实际主题模块、iframe 主题握手、原生站点与画中画同步使用实际基准或在开关变化时更新。

## 主题色边界

主题色用于主操作、当前位置圆点、开关与进度、未读圆点、链接和关键词、Logo、文本选区。其余选中表面、普通计数、私信气泡、菜单及标签、装饰和编辑边线改用中性颜色。液态指示器、圆角、玻璃、动效和业务节点保持原实现。

`--bew-theme-surface*` 保留为中性兼容别名，避免为配色变更重建组件。背景渐变沿用原持久化键和显示开关，但绘制中性渐变，相应文案同步四种语言。

主操作背景始终使用原始主题色；JS 选择黑/白前景，新浏览器可使用 CSS `contrast-color()`，旧浏览器沿用 JS 计算结果。文字和小圆点的独立对比度校正不回写按钮底色。
