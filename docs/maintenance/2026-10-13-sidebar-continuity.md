# 侧栏搜索与切页连续性

## 实现

- 搜索外观以消息页为准，收敛为 `SidebarSearchControl.vue`：普通实色阅读面、常驻中性细边框、全圆角、单一清除按钮、无背景的筛选图标；清除悬停只改变图标前景。收藏、历史、稍后再看及消息共用该组件。动态页不新增无实际用途的搜索框。
- `PersistentSidebar.vue` 位于 App 页面切换层之外，拥有唯一的侧栏玻璃表面。`LibraryWorkspace`、`WhisperWorkspace` 与消息首屏骨架把原侧栏内容交给该宿主；正文滚动、分页和各页请求归属保持原实现。
- 搜索输入和标题展示由宿主保留同一组件实例，通过 DOM 目标交接进入当前页的原布局位置。`LibrarySearchField` 与 `LibrarySidebarHeading` 是页级参数/事件适配层，没有新增查询或分类状态。相同滚筒结构切页时复用；静态标题与滚筒按各页实际语义切换。
- 离场清理按 binding 身份撤销，不能删除后到的新页绑定。旧页等待异步模块时整个侧栏 inert；卸载后不保留旧页事件/筛选槽位/请求。标题只保留纯展示数据以跨越 out-in 间隙，不使用整页 KeepAlive。
- 搜索控件交接时清理未完成的 IME composition；旧页暴露的 focus 不能抢新页焦点。滚筒交接清理旧键盘预览、滚轮累计和迟到的焦点回调。
- 延续上一轮 0.9 倍的资料库宽度；消息页使用该基准的 **1.2 倍**，整个消息分类工作区一致。宽度值集中在 `variables.scss`。App 使用单个已注册 length 属性作为当前几何输入，正文、侧栏、顶部边缘模糊和 Composer 的原有引用共同读取它。过渡使用现有 200ms / standard token，中途切换由 CSS 从当前值接续，reduced-motion 直接完成；不对玻璃外壳做 opacity 动画。

- 原私信/通知的标题断言迁移到 `LibrarySidebarHeading → SidebarHeadingControl → WheelSelector` 的真实调用链，保留未读、刷新归属等有效要求。

## 重载后的材质与完整收起修订

- 实站确认上一版消息内层仍有与宿主相同的背景和 `blur(14px) saturate(1.8)`；资料库内层是透明 / none。原因是父级覆盖规则与消息 scoped 样式权重相同，后加载的页面样式重新绘制了材质。
- 改为各实际 rail 显式标记 `bew-sidebar-hosted`，由共享 `sidebarSurface.rail` 在组件自己的 scoped 选择器内排除背景、滤镜与重复边框。消息、资料库和消息首屏骨架共用该规则，独立挂载时保留原材质。
- 无侧栏页面不再通过 `v-show` 立即移除外壳。`PersistentSidebar.active` 控制向左滑出，200ms 后隐藏；立即 inert、aria-hidden 且不拦截指针。返回时反向接续，最终不留下固定定位的 transform 包含块；reduced-motion 直接完成。不增加离场定时器、截图副本或业务页缓存。
- 新增真实 SCSS / Vue scoped 编译后的级联回归，覆盖三类 rail 和亮/暗/OLED 色调代入；保留独立材质与宿主透明两种断言。组件回归覆盖关闭后外壳仍挂载、无 display:none 截断和重开后输入实例复用。`pnpm verify:selected-p2` 505 PASS，`pnpm typecheck`、`pnpm lint`、`git diff --check` 均退出 0。
- 实站上一版已检查：收藏、历史、稍后再看搜索框均为同一背景、36px 高；稍后再看输入/清除正常；五类页面正常切换。当前实站尺寸上限为普通 324px、消息 388.8px。没有打开私信会话或执行真实收藏、删除、发送。
- 修订后的产物已确认包含 hosted rail 和 closed 状态；普通网页刷新仍未读到新标记，已请求再次重载。新的材质与退出动画目前由本地预览、实际编译样式和组件回归确认，尚未标记为实站验收完成。

- 滚筒文字、静态标题与独立单行操作的首个图标/文字，改为对齐搜索框和普通侧栏容器左缘，统一读取 `--bew-sidebar-inline-padding`，不再读取顶栏 Logo 内距。保留滚筒的 4px 焦点空间，独立按钮通过共享 padding/inset 保留对称命中面和 hover 留白。
- 资料库与消息首屏的标题骨架同步对齐。真实组件预览实测：桌面标题文字、搜索框外缘和操作图标左侧均为 12px；420px 窄窗均为 8px，无侧栏横向溢出。此轮只改横向定位，字体、页面宽度、竖向间距与交互逻辑保留。

## 2026-10-14 单层材质提亮

- 用户希望接近此前双层侧栏的浅灰观感。共享暗色／OLED 材质的中性白色混入量由 12% 调为 16%，保留 sRGB 混合以接近原填充叠加后的灰阶，不改变透明度、模糊强度、边界或内部控件。
- OLED 在纯黑背景、默认 68% 填充不透明度下，理论合成灰阶由约 `#151515` 提到 `#1c1c1c`。保留单层背景采样，所有共享侧栏、骨架与动态热搜伴随面同步跟随；亮色配方保持不变。关闭磨砂时仍读取同源实色 token。
- 本地真实组件预览确认 OLED 为 `color(srgb 0.16 0.16 0.16 / 0.68)`，玻璃仍为 `blur(20px) saturate(1.8)`，内部 hosted rail 透明且滤镜为 none；亮色、暗色及消息宽侧栏均检查。开发产物已更新，样式 ESLint 与差异检查通过。没有新增运行时逻辑、滤镜层、观察器或动效；尚未重载实站验收。
