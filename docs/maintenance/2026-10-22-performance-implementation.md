# 2026-10-22 性能审查实施

用户批准实施算法审查中的明确问题，同时删除影响性能的过度防御性设计。本次改动覆盖过滤、通知窗口、收藏搜索、私信结果合并及评论树。未根据静态推测改写媒体解码、GPU 模糊或启动拆包。

## 实现

- 普通标题每条仅规范化一次，用户名精确规则用 Set。关注豁免从每个谓词内移到每条数据入口，规则编译由 computed 按关键词依赖复用，移除过滤器的整组深度 watch。
- 保留 JavaScript 正则语法，按推荐批次交给 Worker。普通关键词不创建线程；Worker 缓存上次编译的模式。扩展同源隐藏宿主加载打包好的脚本，不增加 API 权限或使用 blob/eval。可信宿主执行 250ms 预算；调用方的 1s 完成期限处理宿主被移除/扩展重载而没有回复的情况，启动单独允许 5s。后两者属于跨上下文失联处理，不是重试或重复执行。超时提示修改规则，游标在过滤成功且请求仍属于当前账号/页面后才推进。
- 通知复用 `momentColumnIndex` / `CardRowMetrics`。只挂载视口及缓冲窗口、焦点所在项，按源顺序生成 DOM，列追加不重新分配已存在的卡片。只测量已挂载卡片，更新高度索引，使用索引定位未挂载锚点；分类退出保存列与测量快照，重新进入恢复。
- 通知 ID 集合随分页增量维护；首次替换/账号清理时重建或清空。列表使用浅响应式，内容对象由收到的新结果替换。
- 等高通知骨架改用 CSS 网格，删除只剩骨架调用的旧 `MasonryGrid.vue` 与其布局观察器。
- 收藏搜索一次编译查询，WeakMap 按条目缓存规范化文本；内容或搜索字段改变时仅失效对应条目。空查询直接返回原列表。WeakMap 不额外保留已丢弃的条目。
- 私信历史结果使用浅响应式容器和不可变数组。无新匹配时不排序或替换；有新匹配时仅排序本页结果，再线性合并。保留同时间 key 顺序及结果上限。
- 评论树缓存已确认无环的祖先路径，常见深链不再重复全程追溯；深度计算和遍历改为显式栈。移除已经完成环处理后仍存在的遍历去重 Set 和末尾补扫。畸形循环依旧按原顺序断开，不声称所有恶意循环图都达到线性最坏界。

## 构建路径

UnoCSS 文件扫描明确限制在实际 `src` 源文件。i18n 插件增加 Rolldown 原生 hook filter，无关模块不再跨入 JS 回调；必要的语言资源预编译仍保留。

插件回调计时是性能诊断而非编译正确性校验，常规构建不再自动给每个回调做计时；`pnpm build:profile` 显式启用 Rolldown `bundlerTimings`，可复查 `PLUGIN_TIMINGS`。这项诊断改为按需运行，不代表必要的 i18n/UnoCSS 工作已消失；其他构建警告、Lint、类型检查与依赖审计继续执行。

## 正确性边界与冗余收敛

删除的是重复的关注检查、整组深层遍历、全量 ID 重建、无变化排序、评论树二次遍历，以及等高骨架的 JS 布局层。保留网络/存储/跨上下文消息边界校验、账号与请求归属、取消和服务端写入确认。没有新增自动重试队列，也没有把 Worker 失败回退到 UI 主线程执行。

## 验证与证据

- `scripts/verify-performance-implementation.mjs` 纳入 `verify:selected-p2`：普通规则和正则等价行为、前后查找/反向引用、真实独立 Worker 执行、宿主预算与释放、调用方取消/失联/旧端口、收藏编辑失效、10,000 节点评论深链、10,000 项通知的有界 DOM/焦点/追加/列重排/分类快照恢复。
- 另外将优化前后评论树对照运行 5,000 组固定种子的随机图，包含循环、缺失父节点和不同深度限制，输出逐项一致。
- [性能数据](evidence/2026-10-22-performance-implementation.json)：1,000 条标题 × 2,000 规则约 335.70ms → 39.27ms；3,000 节点链约 212.90ms → 1.76ms；10,000 收藏条目的暖索引查询约 7.56ms → 1.19ms。两次本地合成测量有运行波动，不能换算成浏览器 FPS 或整页加速倍数。
- 浏览器视觉与实际扩展页面验收由用户完成。自动检查不会代替实际重载后的扩展同源宿主、通知滚动及布局验收。
