# Bewly_Nocturne

Bewly_Nocturne 是一个面向个人使用习惯定制的 Bilibili 浏览器扩展。它仍是浏览器扩展，不是 macOS、桌面或移动客户端。

## 来源与维护

Bewly_Nocturne 基于 [BewlyCat](https://github.com/keleus/BewlyCat) 开发；BewlyCat 基于 [BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)。本仓库保留原项目历史和贡献者信息。

本项目会继续选择性合并 BewlyCat 上游更新。无冲突的更新正常接收；与 Bewly_Nocturne 定制行为冲突时，经人工审查后保留本地定制。

维护者的分支、Fork、cherry-pick 与上游同步流程见[上游协作流程](docs/maintenance/upstream-workflow.md)。

本项目仅接受外观和视觉交互的issue，底层功能请向上游提交。

本项目假设用户有超过平均线的运行设备，故任何性能和外观之间的取舍都会偏向于外观。

## 夜曲设计一览

Bewly_Nocturne 并不是 BewlyCat 的纯镜像。它在保留 Bilibili 内容能力的基础上，维护一套独立的夜曲视觉与交互设计：

### 添加了

* **独立项目与上游协作体系**：建立 Bewly_Nocturne 的独立品牌、仓库说明及与官方上游隔离的协作流程，夜曲定制与上游更新保持清晰边界。
* **全局页面与顶栏模式**：加入“全 Bewly / 全原版 / 自定义”三档页面模式，并将顶栏模式统一整合至 Dock 设置与全局页面模式。
* **Dock 收起模式**：支持按钮收起、自动收起，以及从完整胶囊连续形变为悬浮圆球的展开与收起动画。
* **深色主题增强**：加入稳定的深色背景派生、OLED 纯黑模式与主题色前景自适应，改善不同主题色和深色环境下的可读性。
* **统一视觉系统**：建立平滑圆角、真实圆形、完整胶囊、语义表面边框及共享顶部渐变模糊等统一视觉规则。
* **设置页面扩展**：加入设置页启动动画、二级导航框架、内存节省分组和云同步状态提示。
* **账号状态隔离**：推荐流、动态流和关注相关缓存按当前 Bilibili 账号隔离，避免切换账号后恢复其他账号的数据。

### 修改了

* **Dock 与顶栏**：优化整体外观、毛玻璃、主题渐变、选中状态、严格居中表现以及展开与收起动画的一致性。
* **设置页面**：统一设置面板、左侧 Dock、关闭按钮、提示卡片和顶部渐变模糊的视觉层级与表面规则。
* **分段选择器**：动态列数、推荐模式、Logo 样式等分段控件统一使用液态滑动高亮指示器，并保持现有 Morph、拉伸与 reduced-motion 行为。
* **媒体与表面轮廓**：统一视频封面、Hover Preview、Skeleton、遮罩、卡片和弹窗的圆角、边框及裁切边界，减少状态切换时的轮廓跳变。
* **原版 Bilibili 页面兼容**：修复原版页面中的灰屏、透明表面、错误定位和插件样式越界覆盖问题，使 Bewly 与原版页面模式更稳定地共存。
* **内容加载**：修复动态、History、关注、订阅和 Watch Later 中的尾页丢失、重复加载、错误分页及异步状态竞态。
* **搜索与过滤**：修复搜索建议旧响应覆盖、无限加载状态、非法 URL 参数以及过滤规则修改后不能立即生效的问题。
* **稍后再看状态**：统一 TopBar、VideoCard、Moments 和原版页面增强中的稍后再看成员状态，并支持同账号跨标签页失效与重新同步。
* **链接净化**：仅移除明确的追踪参数，保留 `p`、`t` 等具有导航、分 P 和播放定位意义的参数。
* **运行稳定性**：修复 iframe、画中画、通知抽屉、扩展重载、Storage 初始读取和云同步中的多项生命周期与状态问题。
* **性能与生命周期**：统一 SPA 路由状态来源，并减少截图、画面比例、触控、播放器及页面增强功能不必要的常驻轮询、监听器和 Observer。
* **上游功能同步**：选择性整合动态、评论、播放器、推荐风控、专栏预览和 TopBar 链接等上游修复，并保留夜曲现有架构与视觉。
* **顶栏搜索框**：移除页面重新加载时由异步宽度校正触发的横向入场动画，保留即时居中。

### 去除了

* **背景图片功能**：完整移除壁纸设置、状态、样式、资源和相关文案。
* **旧顶栏入口与设置**：移除搜索框下方的快捷切换器、透明顶栏及重复的主题渐变配置。
* **重复毛玻璃设置**：将相关控制统一为单一“关闭毛玻璃效果”选项，移除重复或语义重叠的入口。
* **原版首页独立开关**：移除独立的原版首页控制，统一交由全局页面模式管理。
* **液态指示器开关**：保留现有液态滑动视觉和动画，但移除已经无法真实控制运行效果的设置入口。
* **Bewly 全局快捷键**：停止注册与 Bilibili 官方快捷键竞争的全局快捷键，仅保留 Dialog、Drawer、图片查看器、输入控件等组件内部的局部键盘交互。
* **废弃代码与入口**：移除旧 Popup、Options、失效开发任务、已被替代的重复状态和确认无调用的旧实现，同时保留明确用于未来开发的功能骨架。
* **Bilibili Evolved 兼容**：删除第三方顶栏的专用样式、DOM 探测、运行时干预、设置和文案；Nocturne 仅维护 Bewly 与 Bilibili 原生顶栏。

## 本地构建

```sh
pnpm install
pnpm dev
```

开发模式不会压缩内容脚本，以保证长时间监听编译时的函数引用稳定；生产构建仍沿用正常压缩流程。重新编译或重载未打包扩展后，已有 Bilibili 页面需要刷新一次以接入新的扩展上下文。

Chrome 生产版及 ZIP：

```sh
pnpm build
pnpm pack:zip
```

构建目录为 `extension/`，压缩包为 `extension.zip`。
