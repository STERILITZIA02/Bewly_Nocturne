# 三批交互动效引入

按用户对[动效审核](2026-10-12-interaction-motion-audit.md)的确认实施；沿用 `message_feature`，保留消息页和稍后再看页最终外观。未引入动画库、全页快照或新的媒体实例。

## 第一批：交接与反馈

- `PageModeSwitcherButton` 在固定尺寸图标槽内同时交叉淡入淡出，使用既有 fast token；按钮、焦点和命中区域保持同一实例，取消原 300ms out-in 串行等待。
- `useReadyPageTransition` 复用 `createAsyncPageRegistry` 的同一加载 Promise。App、首页分类、设置分类等待当前目标代码就绪后交接，旧页面保留绘制但 inert；快速改选只由最后目标结束等待，旧请求不能拖住新目标。
- 页面交接取消整页透明度过渡，避免侧栏玻璃重现采样边界，也避免同时挂载两个业务数据所有者。没有人为延长网络等待；不在原生页面预载未打开的 Bewly 页面。
- ContextMenu 先完成定位和焦点，再对菜单内容执行短时 opacity/scale；键盘焦点打开和 reduced-motion 不播放该动画，卸载取消。

## 第二批：位置与内容连续性

- 收藏夹展开复用原容器，新增 `selectionScrollAnchor`。每个目录列表只有一个短时锚点所有者，只观察出入两行；新选择接管旧所有者，wheel/touch/pointer/keyboard 意图立即终止校正，卸载释放。
- Masonry 缓存卡片高度和布局，只测新加入、尺寸改变或列宽改变的卡片；原顺序和 DOM 保持不变。分页不重播已有卡片入场，仅可见范围内的位移使用可中断 translate 动画。列数/间距改变、移除、重排和显式重测均有失效路径。
- 收藏刷新不再先清空内容；成功页替换，失败及重试保留原卡片。图文/话题/课程第一页成功后才替换索引；矛盾的空页不会抹掉已知内容。
- 历史刷新暂存结果和游标，成功后提交；失败保留旧记录。原先已到末尾时，失败后的 retry 也会从最新游标重读。单次刷新最多扫描三页，后续沿用正常分页，不增加无界后台扫描。
- 动态、通知与稍后再看的已有旧内容保留、账号归属和媒体清理实现保持复用。

## 第三批：持续开销

- LiquidSegmentIndicator 仅在 moving/scrubbing 时声明 will-change，静止为 auto；移除 Dock 对 width/height 无合成收益的提示。
- 核对当前 `@wxperia/liquid-glass-vue@1.0.9` 的 `GlassFilter` 实现和公开类型：width/height 接受字符串，仅用于 SVG viewport，内部滤镜使用相对坐标。LiquidGlassSurface 改用 100% 宽高，完全移除尺寸 ResizeObserver 和逐帧 Vue 更新，保留真实滤镜、三种形态、色调与实色端点。
- SkeletonBlock 按语义容器分组，在同一 document 共用一个 IntersectionObserver 和一个 visibilitychange 监听。离屏、隐藏页暂停，重新可见恢复；最后一个订阅卸载后释放观察器。没有每条骨架一个 Observer，也没有每帧扫描。

## 2026-10-13：首页缓存过渡重入修复

- 用户报告 Home / ForYou 的 `parentNode → componentUpdateFn → leavingHooks.afterLeave → onLeave` 异常。当前 Vue 3.5.19 的真实 Transition 渲染回归在修复前稳定得到完全相同的 `Cannot read properties of null (reading 'parentNode')`；不是依据错误字符串直接给 DOM 访问加空值兜底。
- 根因是 `useReadyPageTransition` 的缓存就绪分支同步调用 `done()`：out-in 的 afterLeave 立即更新 BaseTransition，而上一次 patch 尚未给占位 vnode 设置 el。只改变刷新 key、或账号就绪后替换初始骨架时，模块 source 不变，尤其容易进入这一分支。
- 统一在 Vue nextTick 后完成离场，并再次核对目标代次、就绪状态和当前离场回调。取消、改选与卸载使旧回调失效；没有人为等待时长、额外请求或双页面数据所有者。模块加载失败仍交给异步组件的现有错误/重试界面处理。
- 新回归覆盖真实 Transition 中的初始账号就绪、连续改 key 刷新、骨架与内容往返，以及已排队离场的取消、目标替换和作用域释放。Chrome 组件预览连续刷新六次后正常显示第七个实例，A→B→C 快速切换最终只显示 C，最多一个数据所有者，控制台无错误。
