# 设置页框架与表面统一设计

## 目标

在不改变现有交互和设置数据的前提下，统一左下角版本提醒与页面重载提示的圆角轮廓，提高顶栏登录按钮和共享关闭按钮的表面对比度，并为播放页、消息页预留可扩展的设置入口。

## 设计

- 版本提醒沿用重载提示的 `--bew-panel-radius`，并明确使用 `corner-shape: round`；不改变位置、尺寸、颜色或弹窗行为。
- 顶栏登录按钮改为主题色实色背景与 `--bew-on-theme-color` 前景；`CloseButton` 的 surface 变体改用现有 elevated solid token，overlay 变体提高黑色表面不透明度。按钮尺寸、事件和状态语义不变。
- 播放页与消息页加入“设置 → Bewly 页面”的二级导航，继续复用 `SettingsCategoryLayout`。两页各有独立空组件目录，当前只显示分类布局自动提供的标题和说明，不增加设置字段、持久化状态或搜索项。
- 四套 locale 同步新增页面名称与说明；README 展示用户可见设计，AGENTS 记录上游同步时必须保护的实现边界。

## 验证

- 静态检查版本提醒和重载提示共享圆角 token，登录与关闭按钮使用实色 token。
- 静态检查二级页面注册、独立组件和四套 locale 完整。
- 运行 `pnpm lint`、`pnpm typecheck`，并使用 Chromium 开发编译确认无编译错误。
